현재 프로그램 `MultiLanguageAI_edge-tts-nn.py`는 **다국어 문장 학습, 번역, TTS 발음, 음성 인식 채점, 학습 통계**를 하나의 Tkinter GUI에서 처리합니다.

## 1. 프로그램 시작

실행하면 다음 순서로 초기화됩니다.

1. Tkinter GUI와 필요한 Python 모듈을 불러옵니다.
2. `speech_recognition`, `pygame`, `requests`, `edge-tts` 설치 여부를 확인합니다.
3. 프로그램과 같은 폴더의 `MultiLanguageAI.json`을 읽습니다.
   - `languages`: 지원 언어와 언어 코드
   - `ui_texts`: 언어별 버튼·레이블 문구
4. `%APPDATA%\MultiLangAI` 폴더를 만들고 다음 파일을 사용합니다.

```text
%APPDATA%\MultiLangAI\
├─ history.json          기존 학습 기록 형식
├─ history.jsonl         현재 학습 기록
├─ translation_cache.json 번역 캐시
└─ cache\                MP3 음성 캐시
```

5. `pygame.mixer`를 초기화해 MP3를 재생할 준비를 합니다.
6. Tkinter 메인 창을 표시합니다.
7. 0.5초 후 오래된 MP3 캐시를 정리합니다.

필수 패키지가 없으면 오류 메시지를 표시하지만, 설정 파일이 없거나 잘못되면 프로그램을 종료합니다.

## 2. 언어 설정

언어 정보는 Python 파일에 직접 고정하지 않고 `MultiLanguageAI.json`에서 가져옵니다.

예를 들어 언어 항목은 다음 구조입니다.

```json
"ko": {
  "name": "한국어 - Korean",
  "gtts": "ko",
  "stt": "ko-KR"
}
```

현재 Python 코드에서 `"gtts"`라는 JSON 키 이름은 호환성을 위해 남아 있지만, 실제 TTS 엔진은 Google gTTS가 아니라 **Microsoft Edge TTS**입니다.

언어 선택 방법은 두 가지입니다.

- `자동 감지`: `langdetect`로 입력 문장의 언어를 추정
- 직접 선택: 사용자가 콤보박스에서 언어 선택

자동 감지에 실패하면 영어로 처리합니다.

## 3. 텍스트 입력과 문장 분리

사용자가 텍스트를 입력하고 **텍스트 불러오기**를 누르면 다음 작업이 수행됩니다.

1. 입력 내용을 가져옵니다.
2. 마침표, 물음표, 느낌표, 줄바꿈 등을 기준으로 문장을 나눕니다.
3. 현재 문장 위치를 첫 번째 문장으로 설정합니다.
4. 언어를 자동 감지하거나 사용자가 선택한 언어로 지정합니다.
5. 화면에 현재 문장과 진행 상태를 표시합니다.

예를 들어 다음 문장은 세 문장으로 분리됩니다.

```text
Hello. How are you? I am fine.
```

**파일 불러오기**를 누르면 UTF-8 텍스트 파일을 읽은 뒤 같은 방식으로 처리합니다.

## 4. 문장 번역

번역 대상 언어를 선택하고 **문장 번역**을 누르면 현재 문장만 번역합니다.

번역은 GUI가 멈추지 않도록 백그라운드 작업으로 실행됩니다. 현재 번역 순서는 다음과 같습니다.

1. 메모리·디스크 번역 캐시 확인
2. 캐시에 없으면 Google GTX 엔드포인트 요청
3. Google GTX가 실패하거나 `429`를 반환하면 Google Chrome 번역 엔드포인트 사용
4. Chrome 번역도 실패하면 MyMemory 번역 API 사용
5. 성공한 결과를 `translation_cache.json`에 저장
6. 화면에 번역 결과 표시
7. 번역 결과를 Edge TTS로 자동 재생

언어 코드는 번역 서비스에 맞게 일부 변환됩니다.

```text
zh-cn → zh-CN
zh-tw → zh-TW
```

번역 결과가 도착했을 때 사용자가 이미 다음 문장으로 이동했다면, 이전 요청의 결과를 현재 화면에 표시하지 않도록 문장 인덱스를 확인합니다.

## 5. TTS 발음

### 현재 문장 듣기

**문장 듣기** 버튼을 누르면:

1. 현재 문장과 언어 코드를 확인합니다.
2. 언어 코드에 대응하는 Edge 음성을 찾습니다.
3. MP3 캐시가 있으면 기존 파일을 사용합니다.
4. 캐시가 없으면 `edge_tts.Communicate()`로 음성을 생성합니다.
5. `.part` 임시 파일에 저장합니다.
6. 생성 성공 및 파일 크기를 확인합니다.
7. 정상일 때만 최종 MP3 파일로 이동합니다.
8. `pygame.mixer.music`으로 재생합니다.

대표적인 음성 매핑은 다음과 같습니다.

```python
"ko": "ko-KR-HyunsuMultilingualNeural"
"en": "en-US-JennyNeural"
"ja": "ja-JP-NanamiNeural"
"zh-cn": "zh-CN-XiaoxiaoNeural"
"zh-tw": "zh-TW-HsiaoChenNeural"
```

음성 생성이 실패하면 최대 3회 재시도하고, MP3 재생 자체가 실패하면 캐시를 삭제한 뒤 최대 2회 다시 합성합니다.

### 번역 결과 자동 발음

번역이 끝나면 번역된 문장을 번역 대상 언어의 Edge 음성으로 자동 재생합니다.

예를 들어:

```text
원문: Hello.
번역 대상: 한국어
결과: 안녕하세요.
```

이면 `ko-KR-HyunsuMultilingualNeural` 음성으로 `안녕하세요.`를 재생합니다.

## 6. 우즈베크어 처리

현재 JSON에 우즈베크어가 추가되어 있는 경우, 키릴 문자 우즈베크어를 Edge TTS가 더 잘 처리할 수 있도록 내부적으로 라틴 문자로 변환합니다.

화면에 표시되는 원문은 그대로 유지하고, Edge TTS에 전달할 때만 변환합니다.

## 7. 발음 연습과 채점

**발음 연습** 버튼을 누르면 `speech_recognition`을 이용해 마이크 입력을 받습니다.

처리 과정은 다음과 같습니다.

1. 현재 언어의 STT 코드 확인
2. 마이크 주변 소음 보정
3. 최대 8초 동안 음성 입력 대기
4. 한 문장당 최대 25초까지 녹음
5. `recognize_google()`로 음성을 텍스트로 변환
6. 목표 문장과 인식 결과 비교
7. 일치한 단어 비율로 점수 계산
8. 날짜와 점수를 학습 기록에 저장
9. 화면에 인식 결과와 정확도 표시

점수 계산은 다음 방식입니다.

```text
목표 문장의 단어 집합에 포함된 인식 단어 수
÷ 목표 문장의 전체 단어 수
× 100
```

따라서 문장 순서나 단어 반복까지 정밀하게 평가하는 방식이 아니라, **목표 문장의 단어가 얼마나 인식되었는지**를 기준으로 계산합니다.

## 8. 이전·다음 문장

- **이전 문장**: 현재 인덱스를 하나 줄임
- **다음 문장**: 현재 인덱스를 하나 늘림

문장이 바뀌면 번역 결과와 발음 연습 결과가 초기화됩니다.

## 9. 학습 통계

**학습 성취도 분석**을 누르면 별도 창이 열립니다.

표시 항목:

- 오늘 평균 점수
- 최근 7일 평균 점수
- 최근 30일 평균 점수
- 최근 7일 막대그래프
- 날짜별 학습 기록 목록

새 기록은 `history.jsonl` 끝에 한 줄씩 추가합니다. 선택한 기록을 삭제할 때만 파일 전체를 다시 저장합니다.

## 10. 백그라운드 처리

번역, TTS 생성, 음성 인식은 `_DaemonThreadPool`이라는 데몬 스레드 풀에서 실행됩니다.

- 최대 4개의 작업 스레드 사용
- GUI가 네트워크 요청이나 음성 인식 때문에 멈추는 것을 방지
- 프로그램 종료 시 데몬 스레드는 함께 종료
- 작업 오류는 `languageai.log`에 기록

전체 흐름을 요약하면 다음과 같습니다.

```text
입력 문장
  ↓
언어 감지 또는 직접 선택
  ↓
문장 분리
  ↓
현재 문장 선택
  ├─ 문장 듣기 → Edge TTS → MP3 캐시 → pygame 재생
  ├─ 문장 번역 → Google GTX → Chrome 번역 → MyMemory
  │                    ↓
  │                 번역 결과 표시 → Edge TTS 자동 재생
  └─ 발음 연습 → 마이크 → Google STT → 단어 비교 → 점수 저장
```

즉, 이 프로그램에서 **TTS는 Microsoft Edge TTS**, **번역은 Google 계열 엔드포인트를 우선 사용하고 실패하면 MyMemory**, **발음 인식은 Google 음성 인식**을 사용하는 구조입니다.
